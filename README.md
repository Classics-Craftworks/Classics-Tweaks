# Classic's Tweaks

Little details matter: subtle texture tweaks for Minecraft, each one toggleable in-game.

## Downloads

Classic's Tweaks is only available on the platforms listed below. Please be aware that downloading it from any other source could result in an altered or potentially malicious version of the resource pack.

## Overview

Visit the [Gallery page](https://modrinth.com/datapack/better-craftables/gallery) for a brief look at what Classic's Tweaks has to offer or check out the [Classic's Tweaks wiki page](https://github.com/Classics-Craftworks/Classics-Tweaks/wiki/All-Tweaks) for a full list!

* **Disc Tweaks** - Subtly widens music discs and unifies their design for a more cohesive look.
* **Dye Tweaks** - Tweaks the dye textures introduced in 1.21.9.
* **Lantern Tweaks** - Tweaks the edges of Soul and Copper Lanterns, to better match the regular Lantern.

Coming Soon:
* **Updated Note Blocks** - Updates Note Blocks to better match the new 26.4 Jukebox textures.
* **26.4 Jukebox Backport** - Backports the new 26.4 Jukebox textures to 1.21.9 - 26.3.

## Toggling Textures

Each part of Classic's Tweaks can be switched on and off from the pack's config button on the resource pack screen. This requires:

* [Respackopts](https://modrinth.com/mod/respackopts) (Fabric or NeoForge)
* [LibJF](https://modrinth.com/mod/libjf) (Respackopts dependency)

Without them, the pack still works, but all changes are always enabled.

## FAQ

### Do I need Respackopts?
No. Without it, the pack still works but all changes are always enabled. Respackopts is only needed if you want to switch individual parts on or off.

### Why only 1.21.9 and newer?
1.21.9 changed how pack formats are handled. While it is possible to support 1.21.8 and older in the same pack, I don't want to maintain support for old versions of the game.

The standalone packs ([Disc Tweaks](https://modrinth.com/resourcepack/classics-disc-tweaks), [Dye Tweaks](https://modrinth.com/resourcepack/classics-dye-tweaks) and [Lantern Tweaks](https://modrinth.com/resourcepack/classics-lantern-tweaks)) have builds going further back, so use those for older versions.

### Can I use the standalone packs alongside this one?
They change the same textures, so there's no reason to enable both. Use either this pack or the standalone ones.

### Why is there no v1 and v2?
Those were my own personal versions from 2021 and were never released publicly, so the first public release starts at v3.
